# Исправление инструментов пакета — update-377b8b7-r2

Приложение остаётся на 377b8b7837037e8aaad4e98530d02588f086edb2.
Все файлы project/ побайтно совпадают с прежним ZIP. Новых миграций нет.
Старый архив сохранён неизменным. Эта редакция не является историческим
полным пакетом r2 для чистой установки.

Исправлено:

- GET 404 и DELETE 404 больше не считаются подтверждением удаления.
  ID остаётся в журнале; сохраняются стадия, безопасный код и время попытки.
  Удаление подтверждает только ответ DELETE с success=true. Потеря ответа
  оставляет неоднозначный остаток для повторной или ручной проверки.
- Собираются строки из operation.messageIds и других известных полей ID.
  ID копии сохраняется в журнале в той же транзакции до удаления OutboundMessage.
  Защита панелей и проверка автора сохранены.
- Планы и журналы имеют version=2. Старые планы не принимаются для apply/retry:
  они могли пропустить ID. После ранее выполненной старой очистки нужен аудит,
  а не повтор старого плана или новый пустой план.
- После запуска, возвращения из очистки и отката инструкция использует
  wait-ready.sh: ожидание обоих health/ready ограничено 120 секундами;
  ошибка останавливает процедуру. Ограничено также зависание команды Docker.

Для уже обновлённого приложения использовать **PATCH-TOOLS.md**. Заменяются
только инструменты и инструкция; повторная установка, сборка приложения,
восстановление БД и перезапуск ради замены файлов не требуются.
Старые cleanup apply/retry до замены не выполнять. Очистка не запускается
автоматически и требует отдельного просмотра, копии и подтверждения.

## Реальные проверки

Проверки выполнены на Node 22.23.2 / npm 10.9.8 в отдельном каталоге `/opt/incident-bot/tmp/fast-uri-security-20260930` прежнего сервера. Рабочие настройки туда не копировались. Интеграционные тесты использовали только `incident_test`, запуск образа — новый отдельный PostgreSQL в закрытой Docker-сети.

- Чистая `npm ci` без прежних node_modules прошла; `npm ls fast-uri --all` показывает только 3.1.8 и 4.1.5.
- `tools/check-fast-uri.cjs` рекурсивно проверяет все установленные экземпляры и их соответствие lock-файлу; проверяет вредоносный порт, скобки в host, percent-encoded регистр, mailto в ветке 4 и обычные URI/IPv6. Дополнительно реальный Fastify компилирует внешние `$id`/`$ref` для body и ответа: правильный запрос — 200, неправильный — 400. Обращений к этим URL нет.

- Typecheck и сборка прошли. Все unit-тесты и расширенные интеграционные сценарии контактов, приватности, личной работы, очередей, восстановления панелей/предпросмотров, фото, согласования, повторной и параллельной доставки: **55 файлов, 598 тестов, 0 ошибок, 0 пропусков**.

## Оставшиеся предупреждения

`npm audit` после обновления: 6 записей пакетов — 3 moderate, 2 high, 1 critical. fast-uri среди них нет. Пакеты: @vitest/mocker, brace-expansion, esbuild, vite, vite-node, vitest. В production runtime (`npm audit --omit=dev`) осталась одна high-запись brace-expansion. Critical относится к dev-зависимости vitest, включая [GHSA-5xrq-8626-4rwp](https://github.com/advisories/GHSA-5xrq-8626-4rwp). Аудит не является проверкой достижимости этих путей в боте и не означает, что устранены все уязвимости проекта.

Чистая установка также предупреждала об устаревших rimraf 2.7.1, lodash.isequal 4.5.0, inflight 1.0.6, glob 7.2.3 и fstream 1.0.12. Эти несвязанные пакеты не обновлялись по заданному ограничению объёма. Их исправление требует отдельной задачи.

Локальные node_modules разработчика не заменены удалённой Linux-установкой; проверенные установки — чистая тестовая установка и runtime-образ. Для получения новых версий в другом окружении необходима `npm ci` или пересборка Docker-образа.

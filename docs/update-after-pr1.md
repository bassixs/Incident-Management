# Настройки будущего обновления после PR №1

Это дополнение для новой версии приложения, не инструкция повторной установки.
PR пока не слит и обновление не развёрнуто. Новый архив не собран.

Сохранить действующие `.env`, базу, вложения, токен, домен и привязки. Никаких
сбросов данных или панелей для этих изменений не требуется. Новых миграций нет.

Чтобы включить согласованный еженедельный отчёт, разработчик вручную добавляет
или обновляет в СВОЁМ `.env`:

```dotenv
BOT_STATUS_USER_IDS=15855542
BOT_STATUS_TIME=08:00
BOT_STATUS_WEEKDAY=monday
```

Получатель заранее открывает диалог с новым ботом. Для нескольких получателей
указать ID через запятую. Для отключения оставить BOT_STATUS_USER_IDS пустым.
Расписание всегда московское. Остальные параметры окружения не заменять.
Настройки применяются при согласованном перезапуске новой версии; сейчас
перезапуск и пробная отправка не выполняются. Подробности и ограничения:
[bot-status.md](bot-status.md).

`deploy/handover/START-HERE.md` и `tools/build_handover_revision.py` сохраняются
как историческая редакция r2 без изменений приложения. Они не являются готовыми
инструкцией и сборщиком нового обновления: в PR изменены приложение и зависимости.
При подготовке нового пакета потребуется отдельный сценарий обновления через
фактический Compose с резервной копией и откатом, сохраняющий текущие данные
и окружение. Исторические утверждения r2 не переносить в новую инструкцию.

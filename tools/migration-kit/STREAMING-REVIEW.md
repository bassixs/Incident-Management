# Потоковый экспорт: редакция для ревью

Основа fc656d247ae0d8921a606c8dfd97e4684932ea02. Runtime, SQL миграций,
образы, CPU 0.5 / память Node 384 MiB / PostgreSQL restore 768 MiB не меняются.

Вместо получения таблицы целиком используются NO SCROLL cursor и FETCH 128.
PostgreSQL вычисляет SHA-256 того же `jsonb_each.value::text`, который хешировался
в Node v1. Расширения и изменения БД не нужны. Одна строка исходных данных всё ещё
должна помещаться в PostgreSQL: абсолютной гарантии для произвольно большого
отдельного значения нет. Строки с неизвестным ID отвергаются.

Поток NDJSON имеет begin/table/row/end, конечные счётчики и SHA-256 всех кадров.
Лимит кадра 64 KiB, очереди Python 8 кадров, backpressure stdout. Дубликаты таблиц
и ID отвергаются уникальным дисковым индексом. Пустые таблицы и их поля учитываются.
Python SQLite cache 2 MiB, mmap выключен, сортировка/индекс на диске; сравнение
построчное, полный список расхождений пишется потоком. Срок экспорта 90 с,
транзакции 180 с и остальные прежние бюджеты сохранены.

`data.json` теперь небольшой manifest формата pr14-18-data-v2 и SHA-256
`data.sqlite`. Оба файла обязательны. Manifest создаётся после успешного завершения
экспортёра и pg_dump. Footer без успешного выхода не является успешной копией.
pg_dump использует тот же pg_export_snapshot; транзакция экспортёра живёт до
окончания dump. Восстановление использует тот же потоковый путь и сохраняет
`restore-differences.json`, включая точное число расхождений.

Нельзя смешивать новые и старые data-snapshot/backup/reconcile. V1 manifest
намеренно отклоняется новыми инструментами; старые копии и комплект сохраняются
для проверки их прежним проверенным механизмом, не конвертируются автоматически.
Ежедневный серверный backup не изменён. Новая попытка допустима только в новом
каталоге после отдельного разрешения; установка не разрешена этой задачей.

Диагностика snapshot/data EOF, exit, OOMKilled, очищенный stderr, принадлежность
временного контейнера и освобождение lock сохранены. Частичный data.sqlite
сохраняется как свидетельство отказа, без backup.json/checksums/restore-result.
Связь с первым ночным exit 139 остаётся недоказанной.

Измерения и результаты настоящего Docker находятся в review/*memory.json,
streaming-result.json, heavy-volume.json и полных протоколах Actions.
